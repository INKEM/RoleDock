# ADR-0002：语义继承

- 状态：已接受（P0）
- 关联：`docs/spec/objects-and-state-machines.md` §2、`docs/spec/adapter-contract.md` §3

## 背景

会话继承需要把上一代角色的知识带给新会话。宿主原生 fork 看似直接，但上下文分享范围不可证明、跨 Harness 不可移植，且会把私密对话与模型隐藏状态一并带入。

## 决策

继承的**通用分支路径**是"新建宿主会话 + 载入 BootstrapBundle"：从不可变 Checkpoint 构造只含可分享语义知识的 bundle，新会话确认载入后，在事务内比较并交换主指针。原生 fork 仅作为协商能力下的体验优化，永远不成为正确性依赖。凭据、私人聊天、活跃进程与模型隐藏状态不进入任何 bundle。

## 后果

- 正面：跨 Harness 一致；继承材料可审计（哈希、来源、待办）；新旧代次权限边界清晰（激活后旧实例撤权）。
- 负面：上下文不如原生 fork "完整"；交接质量依赖 Checkpoint 的引用与待办登记，框架只能帮助用户判断完备性，不保证总结无遗漏。
