# ADR-0005：声明式角色包

- 状态：已接受（P0）
- 关联：`docs/spec/identity-and-permissions.md` §2、`packages/protocol/schemas/rolepack.schema.json`

## 背景

角色包需要被任意工作空间安装、校验和审计。如果角色包携带可执行逻辑，安装即引入任意代码执行风险，权限模型也无法静态分析。

## 决策

角色包是**纯声明**：职责说明、文档模板、输出 Schema 与能力需求，全部是数据和模板文件。原型只加载本地包文件，不执行包内脚本；工具调用始终经由宿主及其授权机制完成。`requested_capabilities` 是需求声明而非授权凭据，实际权限由工作空间所有者策略决定。包内路径限制在包根目录内（Schema 层拒绝穿越模式，安装器拒绝越界符号链接），输出 Schema 只允许受限本地引用，禁止运行时从远程加载。包版本与内容哈希进入 BootstrapBundle 与审计记录；更新包不静默改变运行中会话的契约，按显式升级与交接生效。

## 后果

- 正面：安装可静态校验；权限可审计；角色包可独立分发与版本化。
- 负面：角色无法在包内自定义运行时行为，需要行为扩展时走核心的显式扩展点或宿主侧工具。
