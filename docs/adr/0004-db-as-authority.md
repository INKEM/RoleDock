# ADR-0004：数据库为权威来源

- 状态：已接受（P0）
- 关联：`docs/spec/objects-and-state-machines.md` §4

## 背景

角色知识既要支撑运行时校验（所有权、代次、修订、可见性），又要以人类可读的 Markdown 形式被查看与携带。如果 Markdown 文件本身是权威，绕过校验的编辑和并发冲突都无法防范。

## 决策

数据库状态是**实时权威来源**：所有正式发布、指针切换、请求绑定以数据库事务为准。Markdown 导出是**带版本的材料**——每次导出携带修订与哈希，可外带、可阅读；外部编辑不直接回写，必须作为候选更新导入归并（走 `documents.propose` 语义），由所有者重新发布。

## 后果

- 正面：校验与并发控制有单一事实源；导出材料可验证完整性（哈希链）。
- 负面：外部直接改文件无效，需要归并流程；导出材料会随时间过期（通过修订号可检测）。
