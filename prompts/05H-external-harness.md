# P5-H：真实外部 Harness 与会话锚定闭环

前置：P5-A 独立验收通过。读取 COMMON、桌面计划、适配指南与全部未关闭问题。

使用用户指定并授权的真实外部 Harness，核查官方当前会话身份、人类事件、材料载入、独立分支、结果与对账接口及精确版本。缺输入时完成无依赖的适配准备，写具体 BLOCKED 缺口，不猜私有 API，不自建聊天 Harness。

在授权范围内完成：用户在现有外部会话授权角色 → Agent 调用显式锚定 → 当前会话载入固定材料 → 正式角色动作 → 新会话继承 → 旧主撤权 → 独立请求返回可读实际答案 → 收件箱显式采纳。证明不复制私人聊天、不向主会话注入请求、不混淆 Mock／fixture 与真实模型证据。

共享适配契约、重叠请求、权限、取消、期限、恢复及迁移回归必须通过；记录宿主、模型、适配器版本及结果引用，移除凭据。写 P5-H 开发报告待独立验收，同时复验原 P5 总体条件并关闭 G01。通过后停止，不自动执行 GUI 或发布。
