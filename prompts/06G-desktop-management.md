# P6-G：桌面管理 GUI

前置：P5-H 与原 P5 总体验收通过。读取 COMMON、桌面计划、ADR-0007、toolchain 与当前阶段报告。

先验证桌面容器、UI 与 IPC 的可运行基线，依据官方资料精确固定依赖并更新 toolchain，再实现可运行的 desktop 包。RoleDock 管理界面复用单协调器服务，只通过外部 Harness 接入会话，不实现聊天宿主。

实现工作空间／连接、角色库、授权与会话绑定、角色知识、请求收件箱。展示受限能力、载入进度、待对账、接任和撤权；刷新不打开新主会话。渲染层无写库、宿主命令或管理员凭据。已有具体授权不增加重复确认。

按桌面计划验收矩阵，用户只用 GUI 和外部会话完成主要流程，无必需 CLI 步骤；多连接共用单协调器，状态与权限一致。覆盖可恢复错误、键盘操作与空状态，至少在一个目标桌面系统完成打包安装实测。

写 P6-G 开发报告待独立验收，未验证平台如实标注。通过后停止，不自动远程发布。
