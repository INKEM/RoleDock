# P6-G5：知识、历史、候选与迁移

前置：P6-G4 独立验收 PASS。

先读 COMMON、AGENTS、开发蓝图、toolchain、[桌面 GUI 计划](../docs/DESKTOP_GUI_PLAN.md) §5、§6、§13、ADR-0013及前序验收。以当前代码和已定档契约为准；只执行本子阶段。

## 工作

1. 按已定可见性提供 owner 文档／修订／候选读模型；正文经服务按需读取，渲染层不读对象路径或开库。
2. 实现文档目录、历史比较、来源／可见性、checkpoint 摘要／待办、候选基线与冲突、导出／导入原生选择和结果清单。
3. 编辑保留本地草稿；如增加 owner 候选提议，先明确独立来源和审计。导入只创建候选，正式发布／采纳由当前有权角色在原会话完成。
4. 验证撤权、历史不可变、过期基线冲突不丢正文、私密范围、哈希来源和目录边界；不自动合并导出文件或迁移凭据／私人聊天。

## 退出条件

GUI 可查看／比较／迁移知识，并在外部角色显式发布后显示确切新修订；草稿、候选与发布清楚区分。不做向量检索、富文本协同或静默角色升级。

## 交付与停止点

写 `docs/phase-reports/P6-G5-development.md`，状态“待独立验收”；记录实际 HEAD／工作区、源码与契约变化、命令／退出码、失败／跳过项和证据位置。依赖变动先更新 toolchain，架构／权限变化先补 ADR。交独立验收 Agent 按 REVIEW 形成 `P6-G5-review.md`。本阶段完成后停止，不自动进入下一阶段、提交或远程发布。
