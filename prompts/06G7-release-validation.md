# P6-G7：桌面全链、可靠性与安装包

前置：P6-G6 独立验收 PASS。

先读 COMMON、AGENTS、开发蓝图、toolchain、[桌面 GUI 计划](../docs/DESKTOP_GUI_PLAN.md) §15、§16、§17、ADR-0013及前序验收。以当前代码和已定档契约为准；只执行本子阶段。

## 工作

1. 实现 G0 定档的首发 Linux 安装格式和运行时资源布局，在没有仓库 node_modules 的环境安装运行；不打包 ZCode 账户、个人 helper 或测试目录。
2. 逐条执行 GUI-01–GUI-14：真正桌面窗口、原 ZCode 会话、人类确认、Agent 锚定、继承、知识、十重叠请求、真实结果采纳和异常恢复。
3. 补 G-min 遗留真实点击证据及 UI/service/connector 分别退出恢复矩阵，证明不重复任职／支出、不抢外部进程、不混淆撤权与回收。
4. 完成键盘、焦点、目标分辨率、长列表／正文、轮询和资源实测；性能目标按计划记录基线，模型延迟另计。
5. 运行原门禁及新增桌面/E2E/打包检查，区分 fixture 和真实宿主证据；生成 P6-G 总体对照、安装说明和已验证能力清单。

## 退出条件

GUI 全矩阵有证据、安装无需开发仓库／终端构建、原会话与受管请求均真实跑通。交付 G7 和 P6-G 总体验收材料；未通过不转 P6-R、不远程发布。

## 交付与停止点

写 `docs/phase-reports/P6-G7-development.md`，状态“待独立验收”；记录实际 HEAD／工作区、源码与契约变化、命令／退出码、失败／跳过项和证据位置。依赖变动先更新 toolchain，架构／权限变化先补 ADR。交独立验收 Agent 按 REVIEW 形成 `P6-G7-review.md`。本阶段完成后停止，不自动进入下一阶段、提交或远程发布。
